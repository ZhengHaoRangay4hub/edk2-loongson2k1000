# 烧写与恢复（龙芯教育派 LS2K1000LA）

## 0. 固件布局（4MB SPI NOR）

| NOR 偏移 | 大小 | 内容 |
|---|---|---|
| `0x000000` | `0x360000` | EDK II 固件卷（`FVMAIN_SIZE`；全功能构建约用 1.4 MB，`BOARD_MIN` 构建实际只占 `0xF0000`） |
| `0x360000` | `0x00F000` | 进度日志（[BOOTLOG.md](BOOTLOG.md) §2） |
| `0x36F000` | `0x001000` | 诊断裸标记扇区（`LS2K_MARK_BASE`；日志与固件都不得占用，仅 `BOOTMARK_FLASH_ENABLE` 诊断构建会写） |
| `0x370000` | `0x040000` | UEFI 变量存储 |
| `0x3B0000` | `0x010000` | 变量 FTW 工作区 |
| `0x3C0000` | `0x040000` | 变量 FTW 备用区（手册/`fdf.inc:47-60` 口径） |

（**这张表与 [BOOTLOG.md](BOOTLOG.md) §2、`Loongson2K1000Pkg.fdf.inc` 必须逐字一致**；
旧版本这里少了日志区、并把 FV 写到 `0x370000`。）

要点：

- **固件卷与变量区不重叠**，变量写入不会破坏固件本身。
- 镜像有两种尺寸，别混：全功能构建 `UEFI.fd` = `0x360000`；**真机用的 `BOARD_MIN` 构建**
  （`-D QEMU_FIT=TRUE -D BOARD_MIN=TRUE -D BOOT_CRMD=0xb8`）只有 `0xF0000`（983,040 B），
  它落在 1 MB 启动窗口内。刷写时把这份写到 NOR 偏移 `0`，并**只写前 1 MB**
  （`flash_beep3.sh` 的做法）；变量区与日志区首刷保持 `0xFF`。
- 校验只看「回读截断到镜像长度」的比对（`flash_beep3.sh:42-54`）；**不要用 `flash_1m.sh` 旧版的比对**，
  它的长度比较恒为假（见 [BRINGUP.md](BRINGUP.md)「烧写与回读」节）。
- 若你希望烧写整片镜像，可在尾部补 `0xFF` 到 4 MB。

## 1. 备份（必做）

用 SPI 烧录器（CH341A + SOP8 夹子）整片读出 NOR，保存为 `pmon-backup.bin`。
PMON 自带的 `flash` 命令在教育派上可能因写保护拒绝整片写入
（PMON 源码中即有此提示），**以烧录器备份为准**。

## 2. 烧写 EDK II 固件

**方式 A（推荐，不依赖原固件）**：CH341A 将 `UEFI.fd` 写入 NOR 偏移 0。

**方式 B（PMON 仍可运行时）**：串口进 PMON 命令行（开机按 `C`），

```
PMON> load tftp://<服务器>/UEFI.fd      # 载入到内存，记下 PMON 打印的载入地址
PMON> flash 0 0x370000 <载入地址>        # 写入 NOR 起始处
```

各版本 PMON 的 `flash` 参数略有差异，以设备上的 `help flash` 为准。

## 3. 恢复

写回第 1 步的备份镜像即回到 PMON 固件。

## 4. 首次启动自检

- 串口：`115200 8N1`。控制台在 **LVTTL 的 UART3（`0x1fe20300`，教育派 8=TX/10=RX/9=GND）**，
  同时镜像到 RS232 调试口 UART0（`0x1fe20000`，59/60 脚）。**前提是 `0x1FE00428` 的
  `uart0_enable[3:0]` 不是复位的 0x1**（手册表 5-3）——v7 写的是 `0x1FE00420`，
  按手册不产生这个效果，本轮才补上；上机若 8/10 无字而 59/60 有字，先查这两个寄存器；
- HDMI：应显示发光“龙”开机画面与图形化设置中心
  （HDMI 经 I2C1 上的 SII9022A 发送器初始化）；
- 变量区为空，固件自动格式化并创建默认启动项。

## 5. 启动操作系统

OpenWrt 24.10 `loongarch64/generic` 的 `ext4-combined-efi` 镜像写入 U 盘或
NVMe，插入板载接口；启动时在启动菜单里选择该设备，或在设置中心
「启动设置」页把它设为「下次启动」。

## 6. USB3

教育派板载 **ASM1042**（PCIe→USB3）由固件内置的 XHCI 驱动枚举，
无需额外配置；U 盘可插 USB3 口启动。该驱动与 QEMU 回归固件使用的是同一
实现（QEMU 下 USB3 键盘/鼠标已验证）。
